# Adel Aulia — Portfolio

A responsive, static portfolio website built with HTML5, CSS3, and vanilla JavaScript.

## Run locally
1. Extract the project folder if you downloaded the ZIP.
2. Open `index.html` in a modern browser.
3. For a local development server, open a terminal in this folder and run:
   `python -m http.server 8000`
4. Visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `adel-aulia-portfolio`.
2. Open a terminal in this folder and run:
   `git init`
   `git add index.html style.css script.js README.md`
   `git commit -m "Build Adel Aulia portfolio"`
   `git branch -M main`
   `git remote add origin https://github.com/YOUR-USERNAME/adel-aulia-portfolio.git`
   `git push -u origin main`
3. On GitHub, open the repository and go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. The site URL will be shown in Settings → Pages, usually:
   `https://YOUR-USERNAME.github.io/adel-aulia-portfolio/`

If `origin` already exists, check it with `git remote -v`; update it with
`git remote set-url origin https://github.com/YOUR-USERNAME/adel-aulia-portfolio.git`.

## Notes
- No framework, backend, API key, or external API is required.
- Google Fonts is used for typography when internet access is available; fallback fonts are included.
- Project links intentionally point to the supplied GitHub profile because individual repository URLs were not supplied.
- The hero illustration uses initials rather than an invented personal photo.
